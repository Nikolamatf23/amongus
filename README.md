# AmongUs

Razvoj multiplayer igre inspirisane igrom *Among Us*, sa pojednostavljenim funkcionalnostima. Igra uključuje kreiranje partija, nasumičnu dodelu uloga, kretanje po mapi, izvršavanje zadataka, eliminaciju igrača i glasanje. Cilj je otkriti impostora ili eliminisati članove posade.
